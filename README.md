# 留答 · 微信小程序现场社交原型

走到一个地方，看看前人留下的话，在现场接一句。

**核心机制：到场开启交流，离场也可继续。** 新发帖、首次接话必须到场；成功参与后，可以离场读取这一条对话的原文、配图与回复并继续接话。浏览、点赞或去过同一地点不获得其他对话的资格。详见 [离场续聊规则与升级步骤](docs/thread-continuation.md)。

## 已实现

- **附近首页**：全屏场景、地点气泡、可关闭的内容卡片、距离分层、展开回复。
- **完整导航**：自定义「附近 / 留下 / 消息」图标导航，中央发布按钮与底部安全区适配；场景内控件使用原生覆盖组件。
- **演示街区**：Canvas 2D 绘制的第一人称透视场景；拖动转向、俯视切换、模拟步行。为避免画布盖住控件，画布在屏幕外生成背景帧，前景 UI 独立呈现；移动时按需刷新，上限约 12 帧/秒，真机性能仍待确认。所有建筑及示例均为虚构，非贸大实景。
- **真实定位**：GCJ-02 前台持续位置更新，原生地图跟随、回到当前位置、精度提示；可以切换到随真实位置移动的抽象 3D 定位空间。后者没有真实建筑模型，不能用于判断实际道路走向。
- **现场留话**：绑定当前坐标，选择已在附近的地点或命名新地点；支持文字和仅现场相机的图片。演示数据保存在本机；真实模式使用云端接口。
- **现场加入与离场续聊**：首次接话验证到场，参与过的对话可在消息页继续；点赞仍需现场，作者可删除本人留话。
- **联机客户端与云函数代码**：邀请加入、附近共享、分层读取、现场发帖/回复/点赞、私有图片、本人内容删除和回复通知概要。**`liudaApi` 已部署，九个集合、五个索引及存储权限已配置；两项服务端凭据已保存且试点已开启，实际联机仍待确认。**
- **动态页面**：“我参与的 / 我留下的 / 回应”，在历史入口找到自己的具体对话；原文、图片及回复由服务端单独核验资格后读取。

## 在微信开发者工具中使用

1. 选择「导入」，目录选包含本 README 和 `project.config.json` 的项目根目录（从 GitHub 克隆后通常叫 **liuda**），不是里面的 `miniprogram`。
2. AppID 使用 `wx755951e5f06c6cea`；项目名称为 `liuda-miniprogram`。配置已指定 `miniprogramRoot`，不需要更改。
3. 正常「编译」即可。无需构建 npm。
4. 默认进入演示街区。拖动底部「模拟步行」改变距离；点气泡打开留话；点 × 或街景空白处关闭；拖动场景只转动视角。
5. 「＋ 留下」进入发布，选择或创建具体地点，写话并保存。演示模式也能保存在独立的本机演示区。
6. 地图右上角「更多 → 切换体验模式」可选择 **演示街区 / 真实定位 · 联机留话**，或打开 **加入联机试用**。未配置云环境时会明确显示尚未开放。

如果从旧版项目升级后只显示街景，请重新打开项目并正常编译。项目配置已开启 `coverView`；场景 UI 放在原生覆盖层，模拟步行和导航位于独立区域。WXML/WXSS 热更新可能重建 Canvas 节点，应重新编译恢复画布，不能把热更新中的瞬时画面当成完成状态。

此前已在开发者工具实际确认街景、顶部控件、三个地点气泡、留言卡片、模拟步行和图标导航同时显示。云端代码已部署，实际调用及双手机现场使用仍待确认；手机定位已由用户真机反馈确认可用，相机和审核权限仍待确认。

## 手机上使用 GPS

2026-10-20 新增 [逗号热度与地点聚合](docs/map-heat-and-clusters.md)：三级大小/颜色、数量气泡、地图缩放展开与底部推荐/最新列表。客户端重新编译可看演示；不同回复者的真实热度计数需要更新部署 `liudaApi`。

本轮新增了地图缩放/刷新、附近留话切换、当前位置新建地点、运行内存草稿、发布成功页及“我留下的”列表。重新完整编译并扫码预览可加载更新；详细改动和一人体验路径见 [一台手机的体验完善](docs/single-phone-experience.md)。当前仅做语法与 JSON 检查，新交互尚未真机确认。

1. 在小程序管理后台确认 AppID 对 `wx.getLocation`、`wx.startLocationUpdate`、`wx.onLocationChange` 的使用权限，以及适用类目。
2. 配置并发布小程序隐私保护指引，声明实际使用的位置信息、现场图片等用途；代码中已声明位置接口和用途。AppID 为测试号时，以该账号实际开放能力为准，不能绕过权限。
3. 开发者工具点击「预览」，使用有预览资格的微信扫码。需要上传预览代码；本次未代为上传或生成远程预览。
4. 在手机上切换真实定位，先阅读指引并点击官方“同意并继续”按钮，再允许小程序位置权限并开启系统精确定位；到室外走动，地图中心随实际位置更新。隐私指引与手机定位许可是不同环节，详见 [定位与隐私授权](docs/location-privacy.md)。
5. 按 [联机部署指南](docs/cloud-setup.md) 配置同一云环境、部署函数并加入邀请试用后，才能发布真实模式的共享留话。未接通时不会退回本机保存。

定位被拒绝、精度过低或接口没有开通时，页面会明确提示，不会使用模拟位置冒充 GPS。开发者工具模拟器坐标不等于手机现场定位。

### 当前到场参数（开发参数，可调整）

以下距离限制用于新发帖、首次接话、点赞与未参与者发现内容；已参与者的具体对话使用独立续聊资格，读取和回复不要求 GPS。

- 200 米外：地点与数量；50—200 米：开头；50 米内：全文候选。
- 真实模式还要求位置不超过 15 秒、报告的水平误差不超过 30 米，且 **距离 + 报告误差 ≤ 50 米**，才显示全文并允许写入。
- 上述误差是设备估计，不能当成严格的真实误差上界。普通定位不能确认某一层楼、某张桌子或某一级台阶。
- 原始定位用于距离和权限判断；3D 视角仅做视觉平滑，不用于判断到场。
- 当前不做后台定位；离开页面或小程序会停止持续定位。

## 当前边界

**演示可以本机使用；云函数和数据结构已部署，服务端匿名密钥与试用邀请码已由账号持有人填写并保存，试点已开启。** 具体进度见 [部署记录](docs/deployment-status.md)，下一步见 [加入联机试用](docs/finish-cloud-setup.md)。

联机接入需要可用的小程序 AppID、云环境 ID、数据库/存储权限、索引和审核接口。`miniprogram/config/cloud.js` 当前已开启，并指定 `cloud1-d3gkowfe36d11fc12`，云函数名为 `liudaApi`。当前没有真实私聊、支付、会员、礼物兑换或消息推送；回复概要通过轮询获取。

云函数从微信调用上下文取得内部身份，按设备上报的位置、时间和精度分层返回内容，以短期一次性凭证和事务控制写入；审核不可用则拒绝发布。普通 GPS 证据仍可能被伪造，不能承诺精准到桌椅或绝对防作弊。公开上线前还要完成举报、屏蔽、管理处理和运维。

3D 演示几何和真实定位地图分开处理；贸大真实建筑、室内楼层和物件级空间锚点尚未接入。原生地图目前使用标准底图，定制真实底图样式是后续接入工作。

本机演示最多保存 50 条自建留话，每串最多 100 条回复；清除小程序数据会丢失。联机附近最多返回最近 50 条，每串最多 100 条回复。云端本人删除目前为逻辑删除，立即停止公开读取；不代表抹除数据库、图片和备份中的全部副本。旧版本本机真实留言不会自动上传。
