# 附近留话列表重设计

> 初代微信小程序历史文档。当前 App 开发请看 [仓库首页](../README.md)。

日期：2026-10-28。任务：[Issue #16](https://github.com/Vans66660/liuda/issues/16)。

## 设计与交互

- 用标题、数量摘要、分段排序建立面板层级。排序选中态使用灰阶高亮，关闭使用独立的圆形底。
- 取消条目的单边描边。每条留话以有内边距的圆角表面呈现，地点/来源/距离为辅助信息，正文为主体，底部统一呈现互动数、权限状态和进入箭头。
- 隐藏“普通”“有回应”等重复标签，仅热度最高档保留“热门”；推荐和最新排序仍调用原有算法。
- 作者与参与者以“我”“参与”小标签区分，不使用品牌角色充当用户头像。
- 原条目点击是选中地图卡片，因此将“继续聊”文案改为权限提示“可续聊”，保留整行点击查看留话，避免暗示点击即发送或直接开始私聊。
- 大互动数用千/万缩写避免挤压状态；定位过期时不显示旧距离。空列表有独立品牌图形与简短提示。
- 调整滚动区高度预算，适应新增的标题与条目留白；320px 下收紧水平间距，正文仍保留两行预览。

无服务端、数据库、GPS 判定、地图坐标或内容解锁权限变更。普通标签隐藏不改变热度分数与排序。
