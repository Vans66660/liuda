# 地图留话卡片整理

日期：2026-10-28。任务：[Issue #14](https://github.com/Vans66660/liuda/issues/14)。

## 改动

- 顶行显示来源与距离，地点独立成行，权限状态放在右侧小标签；普通热度不再显示，有回应和热门仍保留。
- 去掉仅可点击却像拖拽把手的装饰；右侧保留关闭，操作行保留明确的展开/收起。
- 正文字号与行距收敛，点赞、接话数量和主动作分组对齐；“◌”替换成明确的接话文字。
- 底部不再给 cover-view 设置单边边框，改为独立的 1px 背景色分隔线，避免依赖原生覆盖层的单边边框呈现。收淡外层描边，统一圆角与内边距。
- “在此留话”在左，同组列表与下一条箭头在右，下一条保留无障碍文字说明。
- 过期定位显示“位置待更新”，不再将旧距离当作新鲜位置展示。

没有改动坐标、地图缩放、聚合、热度算法、现场权限或云端接口。关闭、展开、点赞、进入对话、在此留话、同组列表和切换下一条仍绑定原有处理函数。
