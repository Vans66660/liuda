## 需要准备的两项信息

1. 可使用云开发、定位接口和必要内容审核接口的正式小程序 AppID。
2. 与这个 AppID 关联的云环境 ID（Env ID）。两部手机必须使用同一个环境。

Env ID 是环境标识，可以发给协作开发者。AppSecret、腾讯云 SecretKey、后台匿名密钥和邀请码不要粘贴到公开代码或聊天。

## 代码结构

- `cloudfunctions/liudaApi/`：联机接口，依赖固定为 `wx-server-sdk@4.0.2`。
- `cloudfunctions/database.rules.json`：九个集合的客户端权限目标。
- `cloudfunctions/storage.rules.json`：私有图片存储权限目标。
- `cloudfunctions/indexes.json`：需要在云数据库创建的索引清单。
- `miniprogram/config/cloud.js`：客户端环境配置。
- `miniprogram/services/api.js`：云调用、邀请加入、到场凭证、上传和按权限读取。
- `miniprogram/services/repository.js`：演示与联机数据的统一入口。

## 开通与部署顺序

### 1. 打开真实云环境

使用有该小程序开发权限的微信登录开发者工具，打开云开发控制台。选择已有环境，或由账号持有人完成环境开通。确认环境绑定到正确 AppID 后记下 Env ID；具体可用资源和计费方案以控制台为准。

如果更换 AppID，在 `project.config.json` 中更新 `appid`。服务端的 `LIUDA_APP_ID` 也必须匹配。不要为了调用接口而关闭校验或伪造账号。

### 2. 创建数据库集合并关闭客户端直读直写

创建以下集合：

```text
liuda_members
liuda_scenes
liuda_posts
liuda_comments
liuda_presence
liuda_ops
liuda_likes
liuda_photos
liuda_events
```

每个集合都在控制台的安全规则中设为：

```json
{ "read": false, "write": false }
```

`database.rules.json` 是逐集合配置清单，不是可以直接粘贴成单个集合规则的内容。所有读写由 `liudaApi` 云函数执行，客户端不直连数据库。这样不能通过修改客户端直接读取远处全文、评论或内部作者身份。

### 3. 建立索引

按 `cloudfunctions/indexes.json` 创建索引：

| 集合 | 字段 |
| --- | --- |
| liuda_posts | location：地理位置 2dsphere；state：升序 |
| liuda_posts | owner：升序；state：升序；createdAt：降序 |
| liuda_comments | postId：升序；state：升序；createdAt：升序 |
| liuda_likes | owner：升序；active：升序；postId：升序 |
| liuda_events | owner：升序；createdAt：降序 |

附近查询使用地理索引，范围 350 米，最多返回最近 50 条。200 米之外只返回地点概要和数量；50—200 米返回开头；满足到场条件才返回全文。私密字段不会包含在公开响应里。

### 4. 将云存储设为仅管理员可读写

在云存储安全规则中设置：

```json
{ "read": false, "write": false }
```

云函数拥有服务端访问能力，客户端不能直接获取云文件。图片上传和读取走云函数，读取时重新检查地点与位置，不向客户端下发可绕过距离限制的文件 ID 或长期公开链接。

当前图片会压缩到最长边 1024 像素，最多 512KB，只接受 JPEG/PNG。需要账号具备 `security.imgSecCheck` 的实际可调用权限；接口不可用时会明确拒绝图片，不会绕过审核。可以先用纯文字完成联机闭环，再处理图片审核的账号准入或迁移到适用的审核服务。

### 5. 配置云函数

在开发者工具中为 `cloudfunctions` 选择该环境，然后对 `liudaApi` 选择“上传并部署：云端安装依赖”。本环境目前在控制台显示 Node.js 16.13，包的最低运行版本声明已与之对齐。核心依赖 `@cloudbase/node-sdk@3.17.2` 的官方包声明为 Node.js >=12；这项元数据核对不等于已确认所有云端传递依赖和实际运行结果。超时设为 30 秒；依赖安装由云端完成，无需在小程序端构建 npm。

云函数需要以下环境变量，模板见 `.env.example`：

| 变量 | 用途 |
| --- | --- |
| LIUDA_APP_ID | 实际使用的小程序 AppID，和调用者上下文匹配 |
| LIUDA_ALIAS_SECRET | 至少 32 字符的随机密钥，生成内部身份与串内匿名称呼；固定保存在服务端 |
| LIUDA_INVITE_CODE | 至少 16 字符的随机试用邀请码，只给参与者 |
| LIUDA_PILOT_ENABLED | 初始为 false，数据库和存储权限配置完成后才设 true |

不要把示例占位词当作真实密钥。匿名密钥改变会让内部身份映射改变，试用期间应保持不变。云函数 `config.json` 已声明文本与图片审核接口；声明不代表已获得账号权限，发布前必须确认实际可调用。

文本发布与回复使用 `security.msgSecCheck` 的审核结果，通过后才写入；审核超时、接口无权限或结果不通过都不会发布。

### 6. 填入客户端环境

修改 `miniprogram/config/cloud.js`：

```js
module.exports = {
  enabled: true,
  envId: 'cloud1-d3gkowfe36d11fc12',
  functionName: 'liudaApi'
}
```

重新完整编译。配置完成后仍需实际部署函数，不能只修改客户端开关。

## 两部手机怎么用

1. 将相应微信加入这个小程序的开发/体验访问范围，通过开发者工具生成当前版本的预览，或使用有权限的开发/体验版本打开。预览上传与体验成员管理由账号持有人完成。
2. 手机 A 和 B 都从首页左上角进入“加入联机试用”，输入同一个服务端邀请码。界面不会公开微信头像、昵称、OpenID 或可跨地点关联的个人主页。
3. 两人到同一个室外位置，允许位置权限；首页显示真实地图和“联机已连接”。
4. A 选择或创建当前地点，留下一句文字；提交成功后，B 的附近页会在约 8—9 秒的轮询间隔后更新，实际还受网络影响。
5. B 走近打开留话，看到全文并现场接一句；A 打开对话页，会在约 6 秒的轮询间隔后看到新回复。消息页也能看到有人回复的通知概要。
6. 离开现场后，后台会拒绝新的公开回复。重新靠近、取得有效位置后才可以接话。已经被看到、截图或另行保存的内容无法远程收回。

## 到场检查的实际含义

每次云端写入使用新的短期、绑定账号和操作对象的一次性到场凭证；服务端重新检查位置时效、精度和距离，并在事务中消费凭证与写入内容。请求编号使网络重试不会重复发帖或重复回复。

当前条件为位置不超过 15 秒、报告精度不超过 30 米、距离加报告误差不超过 50 米。凭证有效 30 秒，凭证过期必须重新取得。客户端时钟与服务器的偏差通过云响应估计校正。

这些仍是**设备上报位置证据**。服务器无法仅凭普通手机 GPS 证明设备没有修改定位，也不能确认到某个楼层、桌椅或台阶。邀请码只限制试用范围，不能把客户端证据变成不可伪造的物理证明。

## 当前运维与上线边界

- 这是邀请制现场试用版本，不是公开运营完成版。付费、私聊、礼物和真实校园三维模型仍未接入。
- 云端内容没有自动从旧版本本机留言迁移，防止未经选择上传历史位置、照片或文字。
- 删除本人留话目前是服务端逻辑删除：立即停止公开读取和回复，不应宣称已经抹除所有数据库与备份副本。
- `presence` 和 `ops` 文档为审计和幂等记录；目前没有自动保留期清理任务。过期凭证即使仍在数据库里也不能使用。
- 图片上传后若最终没有发帖，会成为私有的 staged 文件记录。管理员需要定期处理过期 staged 文件以及已删除留话的图片；当前未部署自动清理任务。
- 本机图片查看缓存会在退出对话、离场或进入后台时尽力清除；异常退出可能留下缓存，公开试点前需要补上启动清理和完整存储策略。
- 还需补举报、屏蔽、管理审核、异常定位识别和更完整的运维，再扩大试点。
