# 图书馆周边 · 夜游版画样板

日期：2026-10-27。对应 Issue #6。入口：`art-sample.html`。

## 实现内容

- 用已整理的 67 个 OSM 对象作为几何底层，初始视角聚焦校园西南部图书馆与书香广场一带。
- 墨蓝底色、暖砂色道路、金色和灰蓝屋顶、版画排线及装饰植被构成艺术表现；文字、留言和模拟蓝点使用独立图层。
- 支持鼠标拖动、滚轮、按钮与双指缩放。获得焦点的地图也支持方向键平移；回位按钮恢复当前屏幕尺寸的初始取景。
- “看原始轮廓”只切换材质和装饰，不切换投影、几何或相机状态。建筑落脚轮廓保持源数据；阴影、屋顶内边线不作测绘信息使用。
- 白逗号复用小程序现有 PNG。图标逻辑尺寸 44×50，地面锚点为 (22,46)，CSS 底部补偿 4px，使地面圆点对应地图坐标，缩放时不改地点坐标。
- 两处留言和回复均为本地示意；可展开、关闭、点赞及查看接话。没有上传、持久化或真实用户内容。
- 手机窄屏使用不同初始取景及横向缩放工具；打开留言卡片后收起缩放按钮。模拟蓝点位于卡片下方，不覆盖卡片文字。

## 数据与艺术表现分层

| 层 | 数据来源 | 可否用于定位判断 |
| --- | --- | --- |
| 建筑、道路几何 | `data/uibe-osm-wgs84.geojson` | 仅作待核验参考，精度未知 |
| 图书馆、求索楼文字 | OSM 名称及已有官方图对照 | 区域标签，不是入口坐标 |
| 书香广场标签 | OSM 封闭步行道 way/996319884 的候选匹配 | 不可，待现场核对 |
| 树木、灯光、铺装与屋顶细节 | 固定随机种子的代码绘制 | 不可，均为艺术示意 |
| 蓝点、留言位置与内容 | 样板内显式声明的演示数据 | 不可，未读取 GPS |

投影使用 WGS84 校园参考纬度附近的局部等距近似，坐标单位为米。建筑/道路、标签、留言、模拟蓝点共用相机参数。道路可见宽度、阴影偏移和屋顶材质为显示设置，没有对应实测宽度或高度。

图书馆轮廓较简化；OSM 标记为求索楼的大轮廓与官方图中的细分建筑群仍存在差异。本样板保留来源形状，没有假设新增墙角、入口、楼层或可通行路径。正式重绘前应补齐建筑群结构，核对书香广场及采集独立检查点。

## 打开与重建

可以从完整仓库直接打开 HTML；素材依赖仓库中的 `miniprogram/assets/brand/liuda-comma.png` 与 `miniprogram/assets/map-pins/h3-n1-grounded.png`。仅分享 HTML 文件会缺失这些素材。

预览也可在仓库根目录启动本地静态服务，然后访问 `/docs/campus/uibe/art-sample.html`。该页面的地图数据已经嵌入，不请求地图服务，不加载在线图块，不调用浏览器定位，不访问云端。

```sh
node scripts/build-uibe-art-sample.cjs
```

源模板：`scripts/templates/uibe-art-sample.html`。生成文件：`docs/campus/uibe/art-sample.html`。修改模板或 GeoJSON 后运行构建；不要只修改生成 HTML。此流程采用代码绘图，没有生成或修改参考插画。

## 实际验证范围

构建脚本与生成后的内联 JavaScript 均做了语法检查。已在浏览器检查地图拖动、按钮缩放、原始轮廓切换、留言打开与关闭、回复展开；390×844 浏览器视口下检查卡片和控件布局，修正了蓝点覆盖卡片的问题。页面控制台未报告错误。

截图：`art-sample-desktop.png`（地图）、`art-sample-geometry.png`（源几何对照）、`art-sample-mobile.png`（浏览器模拟手机尺寸的接话展开）。它们不是微信真机截图。

尚未做微信 WebView 验证、真机帧率测量、现场坐标校验或 GPS 对齐。本次未修改小程序客户端与云函数，也没有部署。正式接入前应将渲染模块移植到选定客户端方案，并统一 WGS84/GCJ-02 坐标处理；不能把本样板等同于已完成精细定位的校园地图。
