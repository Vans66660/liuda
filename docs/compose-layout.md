# 现场留话页布局整理

日期：2026-10-27。任务：[Issue #10](https://github.com/Vans66660/liuda/issues/10)。

## 改动

- 显式设置页面按钮宽度及间距，覆盖微信原生按钮的居中窄块布局；刷新、清空和移除照片保持行内次级操作。
- 地点选择、具体位置输入、定位状态及异常入口集中到地点卡片，统一内边距。
- 正文和匿名/字数信息集中到编辑卡片，保留原生输入框的 keyed seed，不修改输入、草稿和 GPS 校验逻辑。
- 拍照按钮与选填说明对齐；发布按钮使用通栏冷白主操作；草稿提示单独一行。
- 发布成功页的两个主要按钮同宽排列，再留一句作为次级操作。
- 350px 以下页面收紧边距和标题字号。按钮在文档流内，页面可滚动，保留底部导航安全间距。
