# 对话页布局与操作整理

日期：2026-10-28。任务：[Issue #12](https://github.com/Vans66660/liuda/issues/12)。

## 用户可见变化

- 标题上方左侧显示来源，右侧对齐刷新和作者的更多操作；距离与时间统一放在标题下方。位置超过已有时效要求时显示“位置待更新”，不再将旧距离呈现为当前位置。
- 续聊状态只保留一处，移除重复说明块。离场接话与现场点赞仍是两项不同的权限。
- 点赞改为紧凑的小按钮，更新位置放在“点赞需到场”旁边。未开放的私聊入口不再显示。
- 正文、回复列表和接话编辑区层级分明。字数和发送按钮同一行，发送按钮有最小宽度，320px 下保持单行。
- 删除入口移到作者的“更多”菜单，仍需原有删除确认；返回地图保持独立的次级操作。
- 为点赞、发送和删除分别记录操作类型，避免点赞时发送按钮也显示正在发送。仅空格不能启用发送。

## 保留的机制

服务端身份与现场权限、首次到场回复、已参与后的离场续聊、请求幂等、图片读取以及删除确认逻辑均未修改。原生输入框继续持有文字；输入事件只更新字数和是否含有效文字，不回写旧 value。

本次只改客户端与开发预览材料，无需重新部署云函数。手机需要重新编译并生成新的预览码。
