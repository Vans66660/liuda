## 下一步操作

1. 在开发者工具正常编译小程序。
2. 点击首页左上角“演示街区”，选择“加入联机试用”。
3. 从本地 `.private/liuda-cloud.env` 复制 `LIUDA_INVITE_CODE` 等号后面的值，填入邀请码框，点击“加入试用”。不要填匿名密钥；凭据无需发到聊天。
4. 成功后会切换到真实定位地图。手机上需通过“预览”扫码进入，并由用户允许位置权限。
5. 实际加入及定位结果确认后，再开展双手机“现场留下 → 另一人走近读取 → 现场回复 → 离场限制”的闭环。
